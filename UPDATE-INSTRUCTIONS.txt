Cathedra FSDP 0.5.24 — updating an existing Office installation

This package updates the app. Keep the existing Office data\cathedra.db containing your newest records.

1. In your existing Office app, create a backup in Backup & Export. Keep a copy outside the app folder.
2. Save any edits and exit Cathedra using its normal exit control.
3. Extract the whole update package to a new folder. Do not copy its files over the existing app manually.
4. Locate the extracted folder that directly contains Cathedra FSDP.exe, _internal and tools. Extract All can create an extra nested folder.
5. Open PowerShell, paste these three lines, then answer the two folder prompts. Enter folder paths without surrounding quotation marks.

$updateFolder = Read-Host 'Full path of the NEW extracted update folder containing Cathedra FSDP.exe'
$installationFolder = Read-Host 'Full path of the EXISTING Office app folder containing data\cathedra.db'
& (Join-Path $updateFolder 'tools\update-office.ps1') -Installation $installationFolder -Package $updateFolder

Example EXISTING installation (use the folder containing your own newest data\cathedra.db):
C:\Users\<your Windows user>\AppData\Local\Cathedra-FSDP

6. Wait for a verified update result showing version 0.5.24 and database_replaced: false.
7. Reopen the ORIGINAL installation using your usual shortcut. Schema 16 is unchanged from 0.5.22; older installations receive the required additive upgrades after a protected snapshot. Check your newest scholars and grant history.

Do not replace the Office data folder with a development database or a clean installation seed. The updater preserves your records, rehearses migration on a private copy and keeps recovery files.

If an error appears, keep its complete message and receipt path. Preserve data, backups and update journals for diagnosis. Do not delete recovery state or manually replace the database.

New in 0.5.24: Paper & Ink Scholar Office redesign, clearer scholar profiles and a four-step editor, real registration analytics and mixed charts. Continue moves to Review without saving; use Save Scholar for the final complete save. Existing Google reporting retains its 15 columns and one grant per row. Follow GOOGLE_SHEETS_SETUP.md for detailed account setup and access troubleshooting.

Annual funding copies retain the program deadline in the same application, while new applications start separately.
